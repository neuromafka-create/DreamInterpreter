# Changelog

## 1.0.0 — 2026-09-29

### Added

- Локальный разговор с толкователем. Системный промпт читается из `docs/02 Системный промпт для агента.md`.
- Страница настроек для любого сервиса с запросами в формате OpenAI. Ключ хранится на компьютере и в браузер не возвращается.
- Темы Intel, AMD и Adobe. В каждой есть тёмная и светлая схема.
- Блок «Размышление» для текста внутри `<think>`, отдельно от толкования.
- Окно приложения: `npm run desktop` или `Толкователь снов.vbs`.
