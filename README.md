# Толкователь снов

Локальное приложение для разговора о сне. В ответ приходит несколько гипотез, а не готовое толкование. Личные ассоциации важнее сонников. Это не приём психотерапевта и не медицинская консультация.

Поведение агента задаёт файл `docs/02 Системный промпт для агента.md`. Приложение читает его при запуске.

## Запуск

Нужен Node.js. Зависимостей у проекта нет.

В браузере:

```
npm start
```

Страница открывается на http://127.0.0.1:4173.

Отдельное окно:

```
npm run desktop
```

Тот же запуск двойным щелчком по файлу `Толкователь снов.vbs`. Окно рисует Microsoft Edge, а если его нет — Google Chrome. Закрытие окна останавливает приложение. Повторный запуск, пока окно уже открыто, открывает ещё одно.

## Подключение

На странице «Настройки» выбирается сервис с запросами в формате OpenAI: Hubris, OpenAI, OpenRouter, Groq, Ollama, LM Studio или свой адрес. Для сервера на этом компьютере можно указать `http://127.0.0.1` и не задавать ключ.

Ключ остаётся на компьютере: в `data/connection.json` после сохранения или в `.env`, пока настройки не сохранены. В страницу ключ не подставляется. Файлы `.env` и `data/` в git не входят. Образец переменных — `.env.example`.

## Оформление

В настройках три темы: Intel, AMD и Adobe. У каждой есть тёмная и светлая схема. Выбор запоминается в этом браузере или в окне приложения. У окна приложения своя память оформления, отдельная от обычного браузера.

Если модель присылает ход мысли в тегах `<think>`, на странице он показан блоком «Размышление», отдельно от толкования.

## Что не записывается

Текст сна живёт только в открытой странице. Приложение не складывает разговор в файл. На подключённый адрес текст уходит лишь для того, чтобы получить ответ.
